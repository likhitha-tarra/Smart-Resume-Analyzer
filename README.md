# 📄 Smart Resume Analyzer

## 🚀 Overview

Smart Resume Analyzer is a web-based application that helps students, freshers, and job seekers understand how well their resume matches a specific job description.

Users can upload their resume and paste the job description of the role they are interested in. The application analyzes both and provides an ATS score, job match percentage, semantic similarity score, matching skills, missing skills, and resume improvement suggestions.

The main goal of this project is to help candidates identify skill gaps and improve their resumes before applying for internships and jobs.

---

## 🎯 Problem Statement

Many candidates apply for internships and jobs without knowing whether their resume properly matches the requirements mentioned in the job description.

Candidates may:

- Miss important technical skills
- Use fewer relevant keywords
- Have missing resume sections
- Find it difficult to identify skill gaps
- Not know how to customize their resume for a specific role

Smart Resume Analyzer provides automated analysis to help solve these problems.

---

## ✨ Key Features

### 📊 ATS Score
Evaluates the resume based on detected skills, resume sections, and resume content.

### 🎯 Job Match Score
Compares the skills required by the job description with the skills detected in the resume.

### 🧠 Semantic Similarity
Uses TF-IDF and Cosine Similarity to compare the content of the resume with the job description.

### ✅ Matching Skills
Shows the skills required by the job that are already present in the resume.

### ❌ Missing Skills
Identifies important job-related skills that were not detected in the resume.

### 📑 Resume Section Analysis
Checks whether important resume sections are present, including:

- Education
- Experience
- Skills
- Projects
- Certifications
- Achievements

### 🤖 Resume Improvement Plan
Provides suggestions to improve the resume according to the selected job description.

### 📥 Downloadable Analysis Report
Allows users to download their resume analysis results as a text report.

### 📄 Resume Format Support
Supports:

- PDF
- DOCX
